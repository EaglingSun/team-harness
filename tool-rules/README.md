# 팀 도구 사용 규칙

검증 도구마다 규칙 문서를 하나 둔다. V 모델의 확인 단계마다 폴더 하나, 그 안에 도구마다 `<도구>_rule.md` 하나다. 단계마다 쓰는 도구가 다를 수 있어 단계별로 나눈다.

| 폴더 | 확인 단계 | 짝이 되는 만드는 단계 | 문서 |
|---|---|---|---|
| `unit-verification/` | 단위 검증 — 정적 분석 · 단위 시험 | 구현 | `DVERA_rule.md`(단위 시험 · `DV-NN`) · `STATICA_rule.md`(정적 분석 · 이 과정에서는 쓰지 않는다) |
| `integration-test/` | 통합 시험 | 설계 | 아직 없다 |
| `system-test/` | 시스템 시험 | 요구사항 분석 | 아직 없다 |

- 아직 문서가 없는 단계는 폴더를 만들지 않는다. 그 단계의 도구를 들일 때 폴더와 문서를 함께 만든다
- 문서마다 같은 절을 둔다: 1 도구 역할 · 2 맡는 시험 · 3 인터페이스(사람 · 도구가 주고받는 방법) · 4 워크플로(작업 순서) · 5 사람이 정하는 것 · 6 사용 규칙 · 7 실습에서 배운 것
- 점검 대상은 6절 규칙이다. 규칙 번호는 도구마다 머리 두 글자를 붙인다(DVERA 는 `DV-NN`)
- 도구를 새로 들이면 이 틀로 문서를 만들고 1 ~ 5 절부터 채운다
