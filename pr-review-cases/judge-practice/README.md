# AI Judge 채점 연습 사례

AI Judge(AI 채점자)를 쓰기 전에, 사람 판정이 정해진 사례로 채점자부터 측정한다(1일차 이론 덱 164 ~ 166쪽). `practice.json` 이 그 사례와 사람 판정이고, `judge.py practice` 가 읽는다.

- 사람 판정은 측정하기 전에 루브릭 기준으로 정했다. 측정 결과를 본 뒤 바꾸지 않는다(154쪽)
- 연습 사례의 참조 사례(`case`)는 `case-01` ~ `06` 이다. Held-out 사례 `case-07` 은 쓰지 않는다
- 「늘 합격만 주는 채점자」도 이 사례에서 일치율 7/12 = 0.58 이 나온다. 일치율 하나만 보지 않는다(166쪽)

## 판정 기준

| 항목 | 묻는 것 | 합격 |
|---|---|---|
| 유형 | 설명한 문제가 `rule` 칸 규칙의 문제인가 | 그 규칙이 다루는 문제다. 규칙 번호만 쓴 설명도 번호가 같으면 합격 |
| 이유 | 코드의 무엇(대상)이 규칙의 어느 조건을 어기는지 말하나 | 대상(값 · 이름 · 주석)과 어긴 조건을 둘 다 말한다. 줄 번호는 대상으로 치지 않고, 길이는 보지 않는다 |
| 쌍 비교 | 같은 자리의 설명 둘 가운데 어느 쪽이 나은가 | 두 항목의 합격이 많은 쪽 · 같으면 비김 |

## 연습 사례 여섯

| id | 참조 사례 · 규칙 | 설명(message) | 유형 | 이유 | 근거 |
|---|---|---|---|---|---|
| P-01 | case-02 · CR-02 | sensor_filter.h 에 선언이 없는 함수 sf_sum 을 static 없이 정의했다 | 합격 | 합격 | 검수 Agent 가 낸 지적. 대상(sf_sum)과 조건(헤더 선언 없음 · static 없음) |
| P-02 | case-04 · CR-04 | 주석 `s_head 를 0 으로 한다` 는 같은 줄 코드 … 새 정보를 더하지 않는다 | 합격 | 합격 | 검수 Agent 가 낸 지적. 대상(그 주석)과 조건(코드 되풀이 · 새 정보 없음) |
| P-03 | case-05 · CR-05 | CR-05 위반이다. | 합격 | 불합격 | 규칙 번호만. 대상도 조건도 없다 |

| P-05 | case-01 · CR-01 | CR-01 위반이다. … CR-01 을 지키도록 고쳐야 한다. | 합격 | 불합격 | 규칙 번호만 되풀이한 긴 설명(장황함 편향 — 165쪽 · 짧은 판은 P-03). 대상도 조건도 없다 |
| P-06 | case-05 · CR-05 | sm_period_ms 안에 TODO 주석이 있다 | 합격 | 불합격 | 경계 사례. 대상(TODO)은 짚었지만 조건(이슈 번호 없음)이 없다 |

## 연습 쌍 셋

순서를 바꿔 두 번 비교해 같은 쪽을 고르는지(일관성 — 164쪽)를 본다. 사람이 고른 쪽은 참고로 적고, 일관성은 정답 없이 계산한다 — 사람과 다른 쪽을 두 번 골라도 일관성은 맞다. 쌍이 셋이라 일관성 값은 0 · 1/3 · 2/3 · 1 가운데 하나다.

| id | 참조 사례 · 규칙 | x | y | 사람이 고른 쪽 | 근거 |
|---|---|---|---|---|---|
| Q-01 | case-02 · CR-02 | P-01 과 같은 설명 | CR-02 위반이다. | x | x 합격 둘 · y 합격 하나 |
| Q-02 | case-01 · CR-01 | 검수 Agent 가 낸 지적(150u 를 이름 있는 상수로) | P-05 와 같은 긴 설명 | x | x 합격 둘 · y 합격 하나. 정보가 모자란 긴 설명을 고르는지 보는 한 쌍이다 — 고른 쪽은 장황함 편향의 단서이고, 일관성과 따로 읽는다 |
| Q-03 | case-04 · CR-04 | P-02 와 같은 설명 | 같은 뜻을 다르게 쓴 설명 | 비김 | 둘 다 합격 둘 |

## 쓰는 법

```
python judge.py practice --rubric rubric-v0.md --out <폴더>
python judge.py practice --rubric rubric.md --out <폴더>
```

- 결과 `judge-<루브릭 이름>.md` 의 「갈린 칸」을 읽고 루브릭 문장을 고친다(166쪽 ③). 같은 연습 사례로 다시 판정한다(166쪽 ④)
- 루브릭의 경계 예시는 이 파일의 설명과 다른 문장으로 쓴다. 같은 문장이면 루브릭이 정답을 품는다 — `judge.py` 가 확인하고 멈춘다
